## ⚙️ 网络设置与设备兼容

　　买到卡只是第一步，让它能上网才是关键。绝大多数情况下，你需要手动设置APN（接入点名称）。这个信息通常运营商会随卡提供，或者一搜就能找到。

*   **MTN**: internet.mtn.com.gh
*   **Vodafone**: internet.vodafone.com.gh

　　把它准确填入手机设置里，重启一下，网络通常就通了。另外，确保你的手机支持当地的主要频段。加纳广泛使用4G LTE，Band 3和Band 20比较常见。现在的手机大多都是全网通了，但老款设备最好还是确认一下。

## 📝 实名注册与合规须知

　　这是个重要环节！加纳的国家通信管理局（NCA）要求所有SIM卡都必须进行实名认证。购买时，你需要出示护照等身份证明文件，由代理商帮你完成注册。未实名激活的卡是无法使用的。

　　这个过程其实是为了大家的安全着想，虽然多了一个步骤，但能有效减少诈骗电话等问题。记得从正规商店或授权代理商那里购买，避免买到已注册或来路不明的卡，后续麻烦无穷。
